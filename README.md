# Stock Market Analysis Chrome Extension

A Chrome extension that provides real-time stock market analysis, trends, and insights directly in your browser.

## Features

- Real-time stock price tracking
- Technical analysis indicators
- Market news integration
- Customizable watchlists
- Price alerts and notifications
- Historical data visualization
- Portfolio performance tracking

## Installation

### From Chrome Web Store (Coming Soon)
1. Visit the Chrome Web Store
2. Search for "Stock Market Analysis"
3. Click "Add to Chrome"

### Manual Installation (Development)
1. Clone this repository:
   ```
   git clone https://github.com/notlazykid/chrome-extension.git
   ```
2. Open Chrome and navigate to `chrome://extensions/`
3. Enable "Developer mode" in the top-right corner
4. Click "Load unpacked" and select the extension directory

## Usage

1. Click on the extension icon in your Chrome toolbar
2. Enter stock symbols to track
3. Customize your dashboard with preferred indicators and charts
4. Set up alerts for price movements

## Technologies Used

- JavaScript
- HTML/CSS
- Chrome Extension API
- Financial data APIs

## Development

### Prerequisites
- Node.js and npm

### Setup
1. Install dependencies:
   ```
   npm install
   ```
2. Build the extension:
   ```
   npm run build
   ```
3. Load the extension in Chrome as described in the Installation section
